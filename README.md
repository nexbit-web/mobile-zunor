# Zunor — мобильное приложение

iOS и Android. Отдельный git-репозиторий в рабочей папке `zunor/`. Бэкенд —
сайт из соседней папки `../web`: его `/api/*` и вход `/api/auth/*`.

## Стек

| Что         | Чем                                                                                                                         |
| ----------- | --------------------------------------------------------------------------------------------------------------------------- |
| Платформа   | **Expo SDK 58**, React Native 0.88, React 19.3, New Architecture                                                            |
| Компилятор  | React Compiler — мемоизация без `useMemo`/`useCallback` вручную                                                             |
| Навигация   | Expo Router: маршруты-файлы в `src/app`, типизированные ссылки, **системные вкладки** (`NativeTabs` — Liquid Glass на iOS 26) |
| Стили       | **Uniwind** — Tailwind 4 для React Native; цвета — те же токены, что в кабинете сайта (`src/global.css`)                    |
| Данные      | TanStack Query: кэш, повтор, догрузка, обновление при возврате в приложение и при появлении сети                            |
| Вход        | better-auth `~1.6.34` + `@better-auth/expo` (та же версия, что на сайте): сессия в SecureStore                              |
| Иконки      | Hugeicons Stroke Rounded — тот же набор, что на сайте; во вкладках — системные (SF Symbols / Material)                      |
| Картинки    | `expo-image`                                                                                                                |

## Запуск (dev)

Сборки не нужны. Сайт (бекенд) — либо тестовый деплой на Vercel, либо
локальный `../web`.

**Против Vercel** (сейчас так): в `mobile/.env` —
`EXPO_PUBLIC_API_URL=https://zunor-ten.vercel.app`. Локальный сайт не
нужен.

**Против локального сайта:** убери `EXPO_PUBLIC_API_URL` и запусти сайт
так, чтобы его видел телефон: `cd ../web && npm run dev -- --host`. Адрес
приложение возьмёт само: тот же компьютер, порт 5173 (`src/lib/config.ts`).

### В браузере

1. `cd mobile && npm run web` — откроется `http://localhost:8081`.
2. В Chrome: F12 → значок телефона (Device Toolbar) → iPhone, чтобы
   смотреть в размере телефона.
3. Войди почтой и паролем от аккаунта на том сайте, куда смотрит
   приложение.

С телефона в браузере — `http://<IP компьютера>:8081` (IP — строка
«Metro waiting on exp://…» в терминале); нужен открытый порт 8081, см.
брандмауэр ниже.

Как это устроено: в браузере приложение ходит в `/api/*` на свой же адрес,
а Metro пересылает запросы на сайт (`scripts/dev-api-proxy.js`). Напрямую
мешали бы CORS и cookie. Сессия в браузере — cookie сайта, а не
SecureStore.

Браузер — **для проверки интерфейса и данных**. Не похоже на телефон:
вкладки — веб-версия, а не системные (на iOS нет Liquid Glass), большие
заголовки и жесты назад — только в нативе. Окончательно смотрим в Expo Go.

### В Expo Go

`npm start` → отсканируй QR-код (на iPhone — камерой, на Android — в
Expo Go). Телефон и компьютер — в одной сети. Против Vercel на нём нужна
переменная `ZUNOR_EXPO_GO=1` (иначе сайт не примет вход из Expo Go).

**Если телефон не подключается** — почти всегда виноват брандмауэр
Windows. Открывай только два порта dev-режима (сайт 5173 и Metro 8081) и
только для частных сетей. В PowerShell от администратора:

```powershell
New-NetFirewallRule -DisplayName "Zunor dev" -Direction Inbound -Protocol TCP -LocalPort 5173,8081 -Action Allow -Profile Private
# убрать, когда не нужно:
Remove-NetFirewallRule -DisplayName "Zunor dev"
```

**Безопасность dev-режима:**
- `--host` делает сайт видимым **всем в этой сети**. Dev-сервер не
  защищён, как прод, поэтому только в своей сети (своя точка доступа,
  домашний Wi-Fi). В кафе и коворкинге — без `--host`.
- В dev всё идёт по `http`: пароль и сессия передаются по сети без
  шифрования. Входи тестовым аккаунтом, а не админским.
- Сайт в dev работает с той базой, что указана в `web/.env`. Если это
  боевая база — всё, что делаешь в dev, происходит с настоящими
  данными. Для разработки лучше отдельная ветка базы в Neon.

Изменил `app.json`, `metro.config.js`, `global.css` или пакеты и что-то
не подхватилось (например, «Requiring unknown module») — `npx expo start -c`
(с очисткой кэша).

**Веб — только в dev** (`web.output: "single"` в `app.json`): обычное
одностраничное приложение, без серверного рендера. Раньше там был
серверный рендер, и Metro падал по памяти — `output: "server"` не
возвращать. Собирать веб для публикации не нужно: сайт — это `../web`.

Первое открытие собирается несколько минут, дальше берётся из кэша. Если Metro всё же упадёт с «heap out of memory», запусти с
бóльшим лимитом памяти:
`$env:NODE_OPTIONS="--max-old-space-size=4096"; npx expo start -c`.

Проверки: `npm run typecheck`, `npx expo-doctor`.

**Разные интерфейсы по ролям.** Разделы у обоих одни: главная ·
Замовлення · Чати · Профіль (+ сповіщення). Отличается каркас и главная:

- **Клиент — как приложение ИИ.** Весь экран — чат с Zunor, нижних
  вкладок нет. Круглая кнопка меню слева вверху (или свайп вправо,
  начатый в левой четверти экрана; в разделах — с первого раздела, с
  остальных — от самого края) открывает боковую панель: разделы, «Ваші заявки» (как история
  разговоров: 5 последних — `GET /api/jobs/feed?view=mine&limit=5`, по
  «Усі» — остальные страницами), внизу профиль и большая кнопка «+»
  (новый разговор). Как в ClickUp — слоями: панель лежит под страницей
  на весь экран, страница уезжает вправо поверх неё, скругляется и
  получает тонкую светлую грань, а панель поднимается из глубины
  (`components/drawer`).
- **Чат с Zunor** (как «Нове замовлення» на сайте). Ответ
  печатается по мере прихода (`expo/fetch`, поток NDJSON), есть «Стоп»,
  кнопки-подсказки, карточка готовой заявки. Заявку создаёт система
  (`POST /api/jobs`) после «Створити заявку», с предупреждением о похожей
  заявке (409). Пустой чат — знак Zunor по центру и карточки-подсказки
  над полем ввода.
  Фото к заявке — «+» в поле (до 6, сразу в Cloudinary). Кнопка «Надіслати»
  видна всегда, серая, пока нечего отправлять. Пока нет: голосового ввода
  (в Expo Go нет модуля распознавания речи) и сохранения разговора.
- **Мастер — системные вкладки внизу**, первая — лента заявок поруч
  (`GET /api/jobs/feed?view=feed`, правила ленты считает сервер);
  сповіщення — колокольчиком в шапке. Рядом с колокольчиком — фильтр по
  услуге (`jobs/feed-filter.tsx`), как «Показати: …» на сайте: меню с
  иконками услуг, отбирает уже загруженные заявки по `metadata.service`;
  включённый фильтр — иконка цвета акцента.
- **Колокольчик** — справа в шапке почти каждого экрана: главные
  (замовлення, чати, профиль, разговор с Zunor), заявка, налаштування и
  их разделы. Нет — на самих сповіщеннях и в разделах настроек с кнопкой
  в шапке («Змінити», «Зберегти»). Всегда последний, у края; действия
  экрана («⋯», фильтр) — левее него. С красным числом
  непрочитанных (`GET /api/me/badges`, раз в минуту и при возвращении в
  приложение). Если сповіщення уже открыты ниже (из них пришли в
  заявку) — колокольчик возвращает к ним.
- **Сповіщення** (`app/notifications.tsx`, `GET /api/notifications` — та
  же лента, что на сайте) — группы по дням («Сьогодні», «Учора»,
  «Понеділок», «5 листопада») в сгруппированных карточках iOS; в строке —
  цветная плитка события, ярлык и время, заголовок и подробности,
  непрочитанное — точкой акцента. Касание отмечает прочитанным и ведёт
  туда, куда ведёт сповіщення (заявка и чат — в приложении, заказ и
  профиль — пока на сайте); «Прочитати всі» — над лентой. Число в
  колокольчике правится вместе с лентой. Пока экран открыт — перезапрос
  раз в 30 с (Pusher и push ещё нет). Пустая лента — «Поки тихо» с
  колокольчиком, который раз качнётся, и тихой волной вокруг.
- **Шапка** — поверх экрана, как в Telegram на iOS: контент уходит под
  шапку видимым и к верху экрана плавно размывается и темнеет (на
  Android — только темнеет); в разговоре шапка твёрдая, с чётким краем.
  Название по центру,
  кнопки — круглые на подложке с тонким контуром, «Назад» — такая же
  кнопка со стрелкой (`components/screen-header.tsx`,
  `ui/header-fade.tsx`, `ui/round-button.tsx`, `lib/large-title.ts`). На главных
  экранах мастера наверху название крупно слева прямо в шапке, напротив
  колокольчика, а как только контент уходит под шапку — оно гаснет и
  маленькое проявляется по центру, как в App Store; на остальных и у
  клиента — по центру. Настройки
  называются «Параметри».

**Чати** — как на сайте и в Telegram (`components/chat/*`):
- **Список** (вкладка «Чати» у мастера, пункт панели у клиента) —
  `GET /api/chats`: аватар, имя (с галочкой проверенного мастера),
  последнее сообщение на две строки, время, ✓/✓✓ у своего и число
  непрочитанных цветом акцента. Сумма непрочитанных — на вкладке и в
  панели (один кеш `['chats']`). Два раздела переключателем и свайпом,
  как в «Замовлення»: «Усі» и «Непрочитані». Лупа в шапке — поиск по
  имени и последнему сообщению (поле на месте шапки, круглая «✕»
  справа). ✓✓ в списке появляются
  сразу, как собеседник прочитал (событие `chat:read`), даже если
  разговор закрыт. Чат появляется, когда кто-то нажал
  «Написати» в замовленні — в карточке заказа есть такая кнопка
  (`POST /api/orders/[id]/chat`, как на сайте).
- **Разговор** (`app/chat/[id].tsx`) — поверх вкладок, без нижней панели.
  В шапке имя и «у мережі / був(ла) …», справа фото собеседника.
  Пузыри: свои — справа цветом акцента, чужие — слева серые; серии
  одного автора, плашки дня, время и ✓✓ в углу последней строки, «ред.»,
  ответ с цитатой (касание — к исходному), фото (на весь экран по
  касанию), ссылки и карточка ссылки, реакции. Долгое касание — меню:
  реакции, «Відповісти», «Копіювати», «Змінити» (своё, сутки),
  «Видалити».
- **Поле ввода** — скрепка (фото с подписью), капсула с кнопкой эмодзи
  (панель на месте клавиатуры, «Нещодавні» первыми), «Надіслати».
  Отправленное видно сразу с часиками; не дошло — красный знак и
  «Надіслати ще раз». Черновик держится, пока приложение открыто.
- **Данные** — те же эндпоинты, что у сайта (`/api/chats/[id]/*`), шапка —
  `GET /api/chats/[id]`. Новое приходит живым каналом (ниже), «друкує…» —
  тоже; без канала — перезапрос (сообщения раз в 4 с, шапка — 10 с).
- **Фон** — как на сайте и в Telegram, рисует Skia (Canvas), поэтому
  появляется сразу: в светлой теме зеленоватый градиент Telegram и узор
  сайта поверх него, в тёмной — фон как есть, а весь узор ровно окрашен
  приглушённым цветом акцента.
- **Поле ввода** едет за клавиатурой кадр в кадр (и вверх, и вниз);
  «Надіслати» — круг цвета акцента. Анимации — только короткие
  проявления, без «пружин».

**Живой канал (Pusher)** — `lib/realtime.ts`, тот же Pusher и те же каналы,
что на сайте: сообщения, правки, реакции, ✓✓, «друкує…», новые
сповіщення и строки списка чатов приходят сразу, без перезагрузки. Ключ
приложение берёт у сайта (`GET /api/pusher/config`), каналы подписывает
`/api/pusher/auth`. Только WebSocket. Событие сразу меняет то, что на
экране (строка чата наверх, +1 на вкладке «Чати» и в колокольчике), без
запроса к сайту — как на сайте. Приложение ушло в фон — соединение
закрывается, вернулось — открывается заново и докачивает пропущенное
(как Telegram: иначе «уснувший» сокет минутами считался живым). Пока
подписка на канал не прошла (нет ключа, нет сети, сервер не принял) —
экраны перезапрашивают сами. В dev соединение, подписки, время
авторизации и каждое событие видно в логе Metro (`[Pusher] …`).


«Замовлення»: три раздела переключателем с ползунком и свайпом в любом
месте экрана, как папки в Telegram (`components/swipe-tabs.tsx`; ползунок
и цвет подписей идут за пальцем). Переключатель — часть страницы: при
прокрутке едет вверх со списком и прилипает под шапкой — без плашки под
собой, как «Подати пропозицію»: карточки уходят под него и плавно гаснут
в градиенте цвета фона. «Потяни, чтобы обновить» — свой индикатор на
iOS (`ui/pull-indicator.tsx`): страница вместе с переключателем съезжает
вниз, а прямо под шапкой появляется кольцо акцента со знаком Zunor —
замыкается за пальцем и крутится, пока идёт обновление (системный
RefreshControl остаётся, но невидимый). На Android — системный круг в
цветах приложения. Первая загрузка — скелетон карточек
(`jobs/card-skeleton.tsx`, та же раскладка, что у карточки). Скелетоны
(`ui/skeleton.tsx`) — на всех экранах с загрузкой: уведомления, чаты и
переписка, заявка, разделы настроек, «Ваші заявки» в боковой панели;
спиннер — только при догрузке следующей страницы и в кнопках. Клиенту — Заявки · Активні · Історія
(завершённые и отменённые), мастеру — Активні · Завершені · Скасовані.
Число у раздела — пилюлей: серое — просто «сколько», цветом акцента —
там идёт дело (активные заказы; заявки, когда есть предложения). Над
списком — строка-подсказка, что лежит в разделе.
Заявки клиента — `view=mine` страницами, заказы — `GET /api/orders?status=all`
одним запросом, по разделам раскладываются в приложении. **Карточка
заявки — как на сайте** (`components/jobs/job-card.tsx`, повторяет
web/…/jobs/job-card.svelte): крупное название и шеврон справа; под ним
факты строками с серыми иконками сайта — бюджет жирным, услуга · день
(иконка услуги из `icons/service-icon.tsx`), мастеру — заказчик со
звездой рейтинга и район · расстояние, характеристики через точку
(`jobTags`); описание серым на две строки; внизу — «N тому» (свежие у
мастера — акцентом с «пульсом»), клиенту справа — статус
(`ui/status-pill.tsx`). Карточка — с тонкой обводкой, как на сайте.
«Топ для тебе» — бирюзовая полоса с причинами. **Карточка заказа**
(`components/orders/order-card.tsx`) — прежняя мова
`components/jobs/card-parts.tsx`: иконка услуги на плитке, услуга
акцентом и день, название, характеристики, мастер (или клиент) и цена,
линия и «подвал» со статусом и временем.
Экрана заказа ещё нет — карточка открывает его на сайте.
- **Экран заявки** (`components/jobs/job-screen.tsx`, данные —
  `GET /api/jobs/[id]?open=1`, те же, что у страницы сайта) — в
  сгруппированной подаче iOS по макету владельца: «ЗАЯВКА · 2 ДН ТОМУ»,

## Правила

- **Общий код с сайтом — копией в `src/shared/`**, в каждом файле указано,
  откуда взято. Импорт `../web/...` не работает: сборка EAS клонирует
  только этот репозиторий. Поменялось на сайте — поменяй копию в той же
  задаче.
- **Контракт API:** на сервере поля только добавляются, поэтому новые поля
  в типах `src/shared/*` — опциональные.
- **Иконки — набор сайта** (`<Icon name="…" />`). Изменились на сайте —
  `node scripts/sync-icons.mjs`.
- **Цвета — только в `src/global.css`.** Где `className` не доходит
  (вкладки, шапки, иконки), используй `useColors()` из `lib/theme`: он
  читает те же переменные.
- **Тексты интерфейса — украинский**, как на сайте.
- **Пакеты с нативным кодом ставь через `npx expo install`**: он подбирает
  версию под SDK.
